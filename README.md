# صلّي على النبي ﷺ

مشروع Flutter تجريبي بواجهة عربية RTL.

ملاحظة: هذه نسخة أولية للواجهة فقط. لا تحتوي بعد على خادم أو حسابات حقيقية أو ترتيب عالمي أو تحقق صوتي. يجب مراجعة المحتوى والخصوصية واختبار التطبيق قبل النشر العام.

لبناء نسخة الويب بعد توفر Flutter:
`flutter build web --release`

ملفات النشر الناتجة تكون داخل `build/web`.
